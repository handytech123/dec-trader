# Strategy proposal worker

Paper/shadow-only service for pure strategy evaluation. It consumes point-in-time verified feature
snapshots, applies immutable strategy versions, and records either a validated proposal or an
explicit no-trade decision. Work is idempotent, leased, retryable, and restart-safe.

The worker has no market provider, execution, signer, wallet, order-submission, or
capital-allocation capability. It cannot run strategies in live mode.

Use `--bridge-cfie-control` to evaluate the no-trade pipeline control in shadow mode. Use
`--bridge-cfie-research` to create a point-in-time backtest snapshot for each registered research
candidate. Each candidate is bound to an exact evidence hypothesis ID, and only a finding packet
generated by that hypothesis can populate its evidence fields. The packet must explicitly publish
`developmentResult.strategyEvidence.expectedNetBps` and `replayReproducibility`; the bridge does not
infer tradability from generic statistical significance. Missing or incomplete evidence fails
closed. Each cycle prints aggregate queue status plus per-strategy evaluation, proposal, and
no-trade counts.
